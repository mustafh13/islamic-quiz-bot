# Islamic Knowledge Quiz — Website + Telegram Bot

## কী আছে
- ১২০০+ ইসলামিক MCQ প্রশ্ন
- প্রতি প্রশ্নে ৪টি সম্পর্কিত Option
- প্রতি পরীক্ষায় Random ১০০টি প্রশ্ন
- ১ প্রশ্ন = ১ নম্বর
- মোট ১০০ নম্বর
- প্রশ্ন ১/১০০, লাইভ স্কোর ও ফাইনাল ফলাফল
- Website + Telegram Bot

## Render
Build Command:
`pip install -r requirements.txt`

Start Command:
`gunicorn app:app`

Environment Variable:
- Name: `BOT_TOKEN`
- Value: BotFather থেকে পাওয়া Telegram Bot Token

⚠️ BOT_TOKEN কখনো GitHub-এ প্রকাশ করবেন না।
