# Islamic Quiz + Telegram Bot

Website + Telegram Bot in one Render Web Service.

## Render
Build: `pip install -r requirements.txt`
Start: `gunicorn app:app`

## Environment Variable
Add:
NAME: `BOT_TOKEN`
VALUE: আপনার BotFather থেকে পাওয়া Telegram Bot Token

## Telegram
`/start` → 100-question exam → 4 options → 1 mark each → final score /100.

Never publish your BOT_TOKEN publicly.
